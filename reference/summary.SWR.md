# Summarizes an `SWR` model

A summary of an `SWR` model

## Usage

``` r
# S3 method for class 'SWR'
summary(object, ...)

# S3 method for class 'SWR'
dim(x)
```

## Arguments

- object:

  an `SWR` model object created using
  [trainSWR](https://sschrunner.github.io/SlidingWindowReg/reference/trainSWR.md)

- ...:

  currently unused

- x:

  an `SWR` model object created using
  [trainSWR](https://sschrunner.github.io/SlidingWindowReg/reference/trainSWR.md)

## Functions

- `summary(SWR)`: Summarizes the `SWR` model

- `dim(SWR)`: Returns the number of windows of the `SWR` model
